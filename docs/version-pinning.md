# 업데이트 채널, 버전 고정과 강제 복귀

```sh
cxz use @edge        # 최신 main CI 빌드로 전환하고 edge 선택
cxz use @stable      # 최신 정식 릴리즈로 전환하고 stable 선택
cxz use v0.1.0       # 설치하고 해당 버전으로 고정
cxz use             # 실행 버전·선택 채널·고정 여부(JSON)
cxz use --unpin     # 고정 해제; 프로세스는 그대로 유지
```

`use`는 게시된 `vX.Y.Z` 릴리즈를 받는다. 체크섬·플랫폼·빌드 리비전을 검증한 실행 파일과 릴리즈에 기록된 digest의 Manager 이미지를 사용한다. 소스 빌드 도구는 필요 없다. 채널은 `@edge`, `@stable`로 선택하며 `main`, `edge`, 임의 브랜치는 받지 않는다.

`@stable`은 draft·prerelease를 제외한 가장 높은 정식 버전 번호를 선택한다. 채널 배포 목록은 v0.1.2부터 제공된다. `@edge`는 같은 커밋의 네 플랫폼 실행 파일과 digest 고정 Manager 이미지가 모두 게시된 뒤 공개하는 배포 목록을 사용한다. 채널을 명시적으로 바꾸면 다운그레이드도 허용한다.

채널 선택은 버전 고정을 해제하고 해당 채널의 자동 업데이트 정책을 활성화한다. 주기 확인과 안전한 자동 재시작은 별도 자동 업데이트 PR에 포함되며, 이 기반 릴리즈에는 아직 주기 실행기가 없다. PR 적용 후에는 선택 채널을 추적하되 자동 다운그레이드를 거부한다.

Linux 호스트에서는 현재 실행 파일, 로컬 설치의 Manager, 실행 중인 프로젝트의 Runtime, 실행 중인 세션의 Supervisor와 Agent를 교체·재시작한다. idle을 기다리지 않으므로 진행 중인 작업은 중단된다. 대화 ID, 계정, 모델과 저장된 이력으로 새 실행을 열며 마지막 입력을 자동으로 다시 보내지 않는다. 이미 중지된 세션은 중지 상태로 남는다. 프로젝트 컨테이너와 데이터 볼륨을 재생성하지 않는다. 외부 provider CLI 자체의 버전은 이 명령으로 변경하지 않는다.

같은 로컬 상태 경로를 사용하는 TUI도 고정 완료를 감지해 재시작한다. 저장하지 않은 입력 초안은 유지하지 않는다. 이 기능이 없는 구버전 TUI는 수동으로 다시 열어야 한다. Windows 또는 로컬 Manager 설치 정보가 없는 클라이언트는 현재 클라이언트만 교체한다. SSH로 연결된 호스트와 다른 PC의 클라이언트는 각각 `cxz use`를 실행한다.

고정 중에는 `self-update`와 다른 이미지로의 일반 `install`을 막는다. 자동 업데이트 PR도 고정을 우선한다. `--unpin`은 고정 이전의 채널과 자동 업데이트 설정을 복원한다. 채널을 선택한 상태에서는 고정 해제가 필요 없다. 클라이언트만 고정한 뒤 처음 Manager를 설치하려면 고정을 해제하고 설치한 다음 다시 고정한다.

## 실패 후 재개

파일과 이미지를 먼저 준비한 뒤 요청을 차단하고 구성 요소를 교체한다. 로컬 `use-plan.json`에 채널을 해석한 결과를 고정하고, `use-transaction.json`, 프로젝트 `use-project.json`에 완료 단계를 기록한다. 중간에 실패하면 같은 명령(예: `cxz use @edge`)을 다시 실행한다. 재시도 중 최신 빌드가 바뀌어도 처음 선택한 빌드로 완료한다. 완료한 세션은 중복 재시작하지 않는다. 미완료 상태에서는 다른 버전 선택과 고정 해제를 거부한다. 기존 Manager 컨테이너는 `-before-use-<transaction>` 이름으로 중지된 채 남는다.

복귀 대상이 읽을 수 없는 데이터베이스 버전은 중단 전에 거부한다. 향후 데이터 형식이 변경되는 릴리즈는 별도의 하위 호환 검증이 필요하다. v0.1.0은 자동 업데이트 PR을 시험하기 위한 복귀 기준점이다.

## 자동 업데이트 PR 시험

v0.1.0을 설치·고정해 정상 동작을 확인한 뒤, 고정을 해제하고 PR 버전을 설치한다. PR 시험 중 복귀할 때는 아래 명령을 사용한다.

```sh
cxz use v0.1.0
```

이 명령이 성공하면 모든 로컬 관리 구성 요소가 v0.1.0으로 돌아오고 자동 업데이트는 다시 차단된다.
