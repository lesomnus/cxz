# v0.1.8

웹의 리소스 관리, 대화 표시와 입력 편집을 확장하고, 여러 창에서 사용할 때의 연결과 렌더링을 개선한 릴리스입니다.

## 업그레이드

```sh
cxz use v0.1.8      # 또는 cxz use @stable
```

Git이나 Vite의 UI 갱신만으로 설치된 서버와 실행 중인 supervisor가 바뀌지는 않습니다. 새 서버 기능을 사용하려면 Manager와 프로젝트 runtime도 업데이트해야 하며, 새 supervisor의 동작은 세션을 재시작한 뒤 확인할 수 있습니다.

## 웹 리소스 관리

- 세션·계정 관리, 대화 검색, 공유 메모리, 보조 AI 설정, 사용량·작업 현황에 독립적인 뷰를 제공합니다.
- 계정 추가, 로그인·로그아웃, 인증 상태와 해당 계정을 사용하는 세션 정보를 확인할 수 있습니다. 브라우저의 로그인 스트림은 인증된 Manager를 통해 연결됩니다.
- 세션 참조·secret 입력 보조, 대기 메시지 표시와 다시 입력하기, 세션 리소스 동작을 추가했습니다.
- 대화 로딩 단계와 재시도 상태를 표시하며, 확인하지 않은 응답은 세션 indicator와 Sessions 아이콘의 숫자 badge로 구분합니다.

지원 범위와 남은 차이는 [웹 기능 비교](../web-parity.md)를 참고하세요.

## 대화와 작업 표시

- 에이전트 응답 사이의 작업을 묶어 개수와 아이콘으로 표시합니다. 상세 작업은 대화 영역 안쪽의 우측 다이얼로그에서 확인합니다. 중요한 오류와 질문은 본문에도 유지합니다.
- 오류 이벤트는 붉은색으로 표시하고, 일반적인 실패 작업과 구분합니다. 오류 메시지는 상세 조회로 보완합니다.
- 응답 헤더에 모델·effort와 시각·상대 시간을 두 행으로 표시하고, 메트릭은 고정된 숫자 영역과 아이콘으로 배치합니다.
- Markdown 코드 블록에서 언어 선택과 복사를 지원하며, 표의 좁은 열도 읽을 수 있도록 했습니다.
- 진행 시간 옆에서 background job 수를 확인합니다. Codex의 background terminal 조회를 연결했고, 지원되지 않거나 조회할 수 없는 경우에는 알 수 없는 상태를 실제 작업 수와 구분합니다.

## 입력 편집과 첨부

- 긴 붙여넣기는 전송 중 진행률을 표시하고, 업로드 확인 후에는 압축된 바이트 크기를 표시합니다. 자리 채우기 0은 어둡게 표시합니다.
- chip은 실제 표시 문구만큼의 폭을 차지합니다. 동일한 크기의 chip도 원문을 각각 유지하며, 삭제·Undo·복사·전송과 초안의 커서 복원을 지원합니다.
- 한글 조합 중에도 chip과 코드 블록의 선택·닫기 버튼을 유지합니다. 업로드 완료가 진행 중인 조합을 끊지 않도록 했습니다.
- 지원되는 첨부 연결은 raw HTTP 스트림으로 전달해 불필요한 protobuf 프레이밍을 줄입니다. 다른 연결은 기존 스트리밍 경로를 유지합니다. 자세한 내용은 [첨부 데이터 경로](../attachment-data-path.md)를 참고하세요.

## 연결과 성능

- Manager에 등록된 gRPC 서비스를 Connect로 직접 노출합니다. 웹 전용으로 수동 구현한 서비스와 실제 서버 API 사이의 차이를 줄입니다.
- HTTP/1 환경에서 장시간 구독이 브라우저 연결을 차지해 다른 창의 로딩·Send를 막던 문제를 개선했습니다.
- 대화 가상 렌더링과 개발 모드의 성능 기록을 제한해 스크롤 중 과도한 작업과 메모리 사용을 줄였습니다.
- 즉시 처리되는 승인 요청의 일시적인 카드 표시를 줄이고, 대화·에디터·터미널의 기본 고정폭 폰트를 공통 토큰으로 정리했습니다.

## 공용 UI

다이얼로그의 surface·header·body·footer와 패널 항목을 공용 컴포넌트로 통일했습니다. 트리거를 앞에 표시하는 동작은 실제로 트리거 옆에 열리는 다이얼로그에만 적용합니다.

`BadgedIcon`은 원래 아이콘을 수정하지 않고 badge 주위에서 아이콘을 투명하게 지웁니다. badge의 위치·크기와 CSS 이동을 따라가며, 세션 알림과 마이크 녹음 표시에 적용했습니다. 관련 예제와 회귀 검사는 Storybook에 포함됩니다.
