# v0.1.17

이미지 첨부 미리보기와 공통 UI의 검증 피드백을 개선하고, 세션 알림·Task 캐시·프로젝트 런타임 복구의 안정성을 보완했습니다.

## 이미지 첨부

- 이미지 칩은 파일명 대신 업로드 진행률과 완료 후 용량을 표시하고, 이미지 아이콘으로 구분합니다. 새로고침 후에도 파일 형식 정보를 유지합니다.
- 이미지 칩을 누르면 입력창 위의 비모달 카드에서 미리 볼 수 있습니다. 투명 영역은 체크무늬 배경으로 구분하며, 배율 슬라이더와 드래그 이동을 지원합니다.
- 100%는 원본 이미지 크기입니다. 큰 이미지는 카드에 맞는 실제 배율로 시작하고, 작은 이미지는 자동으로 확대하지 않습니다.
- 업로드 중에는 브라우저의 원본 파일로 즉시 미리 보고, 복원된 첨부는 기존 프로젝트 파일 다운로드 경로로 읽습니다.

## 공통 UI

- 실패한 작업은 레이아웃을 밀지 않는 팝오버로 표시하며, 닫기와 트리거 강조를 지원합니다.
- 메뉴와 날짜 선택은 비동기 작업이 끝날 때까지 열린 상태를 유지할 수 있습니다. 실패하면 선택한 항목에 피드백을 남깁니다.
- PIN 입력의 실패 진동을 슬롯별로 독립 적용하고, 요청 중 비활성화·성공·수정 후 초기화 예제와 사용 가이드를 추가했습니다.
- 헤더가 없는 Card의 상단 여백을 좌우 본문 여백과 맞추고, Switch 표시의 픽셀 정렬을 보완했습니다.

## 세션 알림과 캐시

- 읽음 상태를 서버에 기록하며, 읽음 처리는 화면에 먼저 반영합니다.
- 자동 허용되는 내장 MCP 권한 확인은 질문 알림에서 제외합니다. 실제 사용자 입력이 필요한 질문과 로그인 절차의 알림은 유지합니다.
- Codex 완료 알림을 활성 스레드와 턴에 한정해 중간 응답의 잘못된 완료 알림을 줄였습니다.
- Task 목록과 상세 데이터를 브라우저에 캐시해 다시 방문하거나 새로고침할 때 빠르게 복원합니다.
- SQLite의 정수형 시각 값 변환을 보완했습니다.

## 런타임 복구

- 프로젝트 런타임의 복구 작업과 재시도 이력을 영속화하고, 재시도 횟수·시간 한도를 적용합니다.
- 복구 후 런타임 준비 상태를 확인한 뒤 다음 업데이트를 진행하며, 안전하게 수동 재시도할 수 있도록 했습니다.
