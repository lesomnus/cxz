# v0.1.21

설정 화면과 탐색 메뉴, 계정 사용량 미리보기와 로그 조회를 개선하고, 세션 등록과 실행을 별도 단계로 분리했습니다.

## 설정과 공통 컨트롤

- Language와 Theme을 Appearance에 묶고, 언어를 선택하면 필요한 언어팩을 받은 뒤 바로 적용합니다. 다운로드가 실패하면 기존 언어와 저장값을 유지합니다.
- 에디터 설정을 나란히 볼 때 항목 위치를 맞추고, 입력값의 시작선과 섹션 여백을 정리했습니다. 스위치는 제목·설정 key 옆에 배치합니다.
- 슬라이더의 현재값을 레일 아래 선택 상자로 표시합니다. 값을 눌러 선택하거나 핸들을 연속적으로 움직일 수 있으며, 지정된 값 부근에서 스냅됩니다. 자유값 입력도 별도 선택 위치를 가집니다.
- 글꼴 선택과 Custom·Google Fonts 입력을 한 줄에 배치하고, 추가 안내는 입력칸의 Popover로 제공합니다. Current preview에는 공백·탭·줄바꿈 표시가 나타납니다.
- 공통 체크박스·라디오 메뉴, 아이콘 선택과 검색 가능한 드롭다운을 추가하고, 메뉴·다이얼로그의 여백과 클릭 피드백을 정리했습니다.

## 탐색과 리소스 화면

- 프로필 메뉴에서 Accounts·Settings·Logs에 접근하고, 보조 AI 설정은 Settings에서 관리합니다. 사이드바 아이콘과 항목 순서를 정리했습니다.
- 프로필에 마우스를 올리면 계정별 남은 사용량과 리셋까지 남은 시간을 확인할 수 있습니다. 캐시된 값은 바로 표시하고, 새 값과 숫자는 부드럽게 갱신합니다.
- 프로젝트 아이콘을 저장하고 프로젝트·Task·Memory 필터에서 함께 사용합니다. 프로젝트와 계정의 기본 정보 배치를 정리했습니다.
- Task·Memory 목록에 검색 오버레이를 추가하고, 프로젝트별 파일 탐색기 목록을 연결 안에서 재사용합니다.
- 로그는 한 줄 테이블과 무한 스크롤로 표시합니다. 프로젝트·세션·기간·레벨·카테고리 필터와 필드별 상세 모달을 제공합니다.

## 세션 생성

- `Session.Add`는 DB에 세션을 등록한 뒤 응답하고, `Session.Start`가 로그인 확인과 runtime 준비·실행을 수행합니다. `Resume`도 계속 지원합니다.
- 웹·CLI·TUI는 등록 후 실행을 요청합니다. 로그인이나 시작이 실패해도 이미 등록된 세션을 다시 사용하므로 재시도할 때 중복 세션을 만들지 않습니다.
- 아직 시작하지 않은 세션의 대화 조회와 스트림 연결을 처리하고, 세션 생성 모달은 계정 목록 로딩이나 확인 동작 중에도 높이를 유지합니다.

새 세션 생성 변경을 사용하려면 Manager와 프로젝트 runtime·Supervisor를 함께 업데이트하세요. 기존 DB를 삭제할 필요는 없습니다.
