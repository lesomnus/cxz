# cxz v0.1.0-rc.1 — TUI release candidate

Claude Code and Codex sessions in cxz-owned devcontainers. This is a **prerelease**,
not the completed browser/IDE MVP.

## Included

- xli CLI and reconnecting TUI: create, conversation, approvals, interrupt and resume.
- Durable provisioning checkpoints and ownership-checked retry/reconciliation.
- Default agent/model settings, persistent session model, diagnostics and login hints.
- Docker manager installation, pinned-image update and previous-image rollback.
- Linux amd64/arm64 binaries, SHA256SUMS and multi-platform GHCR image.

## Validation

Full tests, subprocess race checks, vet and GitHub CI passed. Actual Docker tests
covered interrupted provisioning, concurrent retries, foreign-container boundaries,
fresh install, update/rollback, abrupt container loss and SQLite reconstruction.
Codex live conversation/approval/denial/interrupt and two container recreations
with retained vendor conversation passed all seven checks.

## Known limits

- **Claude's second repeated-recreation memory check remains unpassed.** A vendor
  `reasoning_extraction` refusal was observed previously; that does not establish
  that cxz played no role. Current retesting requires user reauthentication.
  No vendor safeguards were disabled.
- Initial vendor login is a user action. No host refresh-token store is copied.
- arm64 artifacts/images are built; native arm64 end-to-end execution is not verified.
- Linux only. No VS Code-created container adoption, browser UI, roster user auth,
  hosted IDE, remote TLS/SSH Docker endpoint support or off-host backup yet.
- Rollback restores the manager image, not past data or the client binary.

Download the correct archive and verify SHA256SUMS. Use the immutable image
reference in `manager-image.txt`, or build the manager from the installed binary:

```sh
cxz install --workspace-root /absolute/projects
cxz doctor
cxz new --agent codex .
```

See [operations](https://github.com/lesomnus/cxz/blob/main/docs/operations.md) for
versioned image installation, user login, recovery and rollback instructions.
