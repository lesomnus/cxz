# v0.1.9

세션 대화 분기, 세션 이동 시 대화 보존, 웹 UI 개발 환경과 공용 컴포넌트 구성을 개선한 릴리스입니다.

## 업그레이드

```sh
cxz use v0.1.9      # 또는 cxz use @stable
```

Fork는 새 서버 API와 supervisor 동작을 함께 사용합니다. Manager와 프로젝트 runtime을 업데이트하고 기존 세션을 Restart해야 사용할 수 있습니다. Vite의 UI 새로고침만으로 실행 중인 서버나 supervisor가 바뀌지는 않습니다.

## 세션 대화 분기

- 대화 입력창의 Session menu → Fork로 같은 프로젝트·계정·에이전트·현재 설정을 사용하는 새 세션을 만듭니다. 새 alias를 부여하고 해당 세션으로 이동합니다.
- 기존에 보존된 대화, 작업 상세, 응답 시각과 메트릭을 유지하며 이후 입력과 응답은 각 세션에 독립적으로 기록합니다.
- Codex는 네이티브 thread fork, Claude는 네이티브 session fork를 사용합니다. 현재 모델·effort·권한과 보조 AI 선호 설정도 이어받으며, 재시작할 때는 분기된 세션을 재개합니다.
- 진행 중인 턴, 미응답 질문이나 대기 메시지가 있으면 먼저 마무리해야 합니다. 같은 요청을 재시도해도 중복 세션을 만들지 않습니다.
- 기본 Codex 중앙 인증은 추가 로그인 없이 연결됩니다. Claude 등 세션별 OAuth 인증은 새 세션 로그인을 거치며 refresh token을 복사하지 않습니다.

분기는 대화와 에이전트 기록을 나눕니다. 같은 프로젝트의 작업 파일은 계속 공유하며 별도의 worktree를 생성하지 않습니다.

## 대화와 탐색

- 세션을 오갈 때 이미 로드한 대화를 메모리에 보존하고, 다른 세션의 응답도 계속 수신합니다. 보조 AI 요약도 세션 이동 시 유지합니다.
- 현재 대화 검색은 로드된 기록에서 즉시 동작합니다. 키워드 강조, 최근 결과부터 이동하기와 스크롤 위치 표시를 제공합니다.
- 스크롤 표시 범위를 바꿀 때 전체 대화를 다시 처리하는 작업을 줄였습니다.
- 대화와 파일 탐색기의 폭 조절 값을 유지합니다. 사이드바는 아이콘과 우측 힌트로 구성하고, 배경 작업만 있는 세션의 활동 표시를 구분합니다.
- 최근 시각은 `Just now`로 표시하고, Markdown의 일반 물결표를 취소선으로 해석하지 않습니다.

## 입력창과 공용 UI

- 전송 응답을 기다리는 동안 입력창 상단 중심에 은은한 회색 맥동을 표시합니다. 동작 줄이기 설정에서는 움직임 대신 고정된 표시를 사용합니다.
- 입력창과 사용자 대화 카드에 공통의 고운 입자 질감을 적용했습니다.
- 패널과 다이얼로그의 여백을 정리하고, 다이얼로그 폼의 입력 배경을 본문과 구분했습니다.
- BackgroundJobs의 목록 카드와 빈 목록, 대화 Fork를 살펴볼 수 있는 Storybook 예제를 추가했습니다.

## 개발 환경

- 공용 UI를 Git으로 고정한 `@lesomnus/nox` 의존성으로 분리했습니다. 개발·sandbox·Storybook에서는 Nox 소스를 직접 읽어 수정 내용을 반영하고, 배포 빌드는 고정된 커밋을 사용합니다.
- `ts/`에서 `npm run dev`를 실행하면 Vite와 Storybook을 함께 시작하고 함께 종료합니다. Vite만 실행하려면 `npm run dev:app`을 사용할 수 있습니다.
- CI와 컨테이너·릴리즈 빌드에서 Nox 서브모듈을 함께 준비합니다. 자세한 내용은 [Nox 개발](../nox-development.md)을 참고하세요.
