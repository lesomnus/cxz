# v0.1.2

`cxz use`에서 버전 고정과 업데이트 채널을 선택할 수 있습니다.

- `cxz use @edge`: 최신 main CI 성공 빌드로 전환하고 edge 채널을 선택합니다.
- `cxz use @stable`: 가장 높은 정식 릴리즈 버전으로 전환하고 stable 채널을 선택합니다. draft·prerelease는 제외합니다.
- `cxz use v0.1.1`: 특정 버전으로 고정합니다. `cxz use --unpin`은 이전 채널과 자동 업데이트 정책을 복원합니다.
- `cxz use`: 실행 버전, 선택 채널과 고정 여부를 표시합니다.

명시적인 `use`는 즉시 설치하고 로컬 Manager·Runtime·Supervisor·Agent를 강제로 재시작합니다. 작업 중인 입력은 중단될 수 있습니다. 채널 변경 시 필요한 다운그레이드는 허용하며, 실패한 전환을 재시도할 때는 처음 선택한 빌드를 유지합니다.

각 채널의 실행 파일은 리비전별로 게시하고, 같은 리비전의 Manager 이미지와 모든 실행 파일이 준비된 뒤 배포 목록을 공개합니다. 채널 선택은 자동 업데이트 정책도 활성화합니다. 주기 확인·안전한 자동 적용은 별도 PR이며 이번 릴리즈에는 아직 포함하지 않습니다.
