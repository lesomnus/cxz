# v0.1.6

웹에서 대화를 **운영**할 수 있게 된 릴리즈입니다. 세션 제어, 질문 응답, 파일 첨부, 터미널 탭과 도킹이 브라우저에 들어왔습니다. 그리고 action 문자열 봉투가 리소스 API에서 완전히 사라졌습니다.

## 업그레이드

```sh
cxz use v0.1.6      # 또는 cxz use @stable
```

상태 스키마는 v0.1.3부터 같은 2이고 프로토콜도 1이라, v0.1.4·v0.1.5에서는 자동 업데이트로도 올라옵니다. v0.1.2 이하(스키마 1)에서 올라오는 경우에만 [v0.1.3의 안내](v0.1.3.md#업그레이드-v012에서는-자동으로-올라오지-않습니다)가 필요합니다.

### 올라오는 동안

교체는 원자적이 아닙니다 — Manager는 설치의 모든 세션이 idle일 때, 프로젝트 Runtime은 그 프로젝트의 세션이 idle일 때, TUI는 5분간 입력이 없을 때 각각 바뀝니다. 그 사이 버전이 섞입니다.

**대화는 영향을 받지 않습니다.** v0.1.6에서 사라진 호출은 `SessionService.Library`(공유 메모리) 하나이고, 입력·응답·승인·이력은 그걸 쓰지 않습니다. 영향을 받는 것은 TUI의 메모리 라이브러리 창입니다 — 한쪽이 상대가 모르는 호출을 하면 그 창만 실패합니다. 양쪽이 같은 빌드가 되면 풀립니다.

## 웹: 대화를 운영할 수 있습니다

지금까지 브라우저에서는 **읽고 보내는 것**만 됐습니다. 이제 세션을 다룹니다.

- **세션 제어**: composer 메뉴에서 Stop/Resume, Restart, Purge, Details. Stop·Restart·Purge는 확인 대화를 거치고, **purge는 API의 dry-run 계획을 먼저 보여줍니다.** Restart는 Stop/Get/Resume 순서를 따르며 run이 바뀌었거나 정지가 실패하면 거부합니다.
- **제목과 별칭 편집**: Details에서 제자리 편집. 수동 제목은 보존되고 자동 제목 생성을 끝냅니다 — 모델을 돌리지 않습니다.
- **파일 첨부**: 드래그 드롭, 네이티브 파일·폴더 선택, 큰 붙여넣기의 텍스트 파일 업로드. **디렉터리는 tar로** 트리·유니코드·긴 경로·빈 디렉터리를 보존해 올립니다. 인증된 HTTP 브리지가 raw 바이트를 기존 `Session.Upload` RPC로 흘려보냅니다. 대기·실패 칩은 Send를 막고, 실패한 업로드는 재시도할 수 있습니다.
- **질문**: 프로바이더 네이티브와 비동기 양식 모두 — 자유 입력, 선택지, 마크다운 미리보기, 필수 응답 키. 번호 탭이 선택·초안·Undo를 유지하고, 필수 응답이 Submit을 막습니다.
- **설정**: 반응형 섹션 열, 테마 SegmentedControl, 상속되는 편집기 폰트(시스템·브라우저 monospace, 사용자 CSS 목록, 지연 로드 Google Fonts). 설정은 여전히 **JSON 문서 하나**입니다.

## 터미널

**처리량.** 지금까지 출력은 매 조각마다 브라우저의 파싱 확인을 기다렸고, 상류의 입력 쓰기가 그 확인 처리를 막을 수 있었습니다. 게이트웨이가 **바운드된 바이트 윈도 안에서 출력을 파이프라인**하고 입력은 별도 바운드 큐로 보냅니다. 작은 조각과 확인은 배치되고, 종료·오류를 보고하기 전에 남은 출력을 흘려보내며, 멈춘 클라이언트는 여전히 타임아웃합니다.

**입력과 선택.** `Ctrl+V` 붙여넣기, `Ctrl+Backspace` 단어 삭제, `Shift+화살표` 되돌릴 수 있는 선택(normal 버퍼). alternate screen 애플리케이션은 수정자 화살표 입력을 그대로 받습니다. 완료된 선택은 자동 복사되고 성공·실패를 알립니다 — General → Terminal에서 끕니다. **PTY를 교체하지 않습니다.**

**탭과 도킹.** 독립 터미널 탭, 드래그 도킹, 중첩 split, 크기 조절 가능한 경계. 추가·닫기·접기·순서 변경·이동이 **살아 있는 셸 연결과 출력, 끝나지 않은 명령을 보존합니다.** 대화/편집기와 파일 탐색기/내용의 경계도 같은 resize 핸들을 씁니다.

ANSI 색은 어두운 배경에서 파스텔·네온, 밝은 배경에서 읽히는 깊은 색조를 씁니다.

## 알림과 초안

완료된 응답과 새 질문이 **조용한 탭 배지**와 TUI의 로컬 소리 신호를 받습니다. 읽지 않은 완료는 세션 행에 표시가 남고, **포커스된 대화가 최신 이력을 보여줄 때만** 해제됩니다. 오류·중단·초기 이력·재연결 중복은 완료 소리를 다시 울리지 않습니다. General → Notifications에서 끕니다. 브라우저 오디오는 사용자 제스처로 열리고 권한 프롬프트가 없습니다.

세션 범위 초안과 붙여넣기 칩 내용이 **새로고침을 넘어 살아남습니다**(탭 로컬 sessionStorage). 수락된 전송은 저장된 초안을 지우고, 거부된 전송은 남깁니다. 완료된 첨부 경로는 복원되지만 중단된 업로드는 파일을 다시 선택해야 합니다.

## 보조 AI 요약이 브라우저에 보입니다

서버는 v0.1.4부터 준비돼 있었는데 웹에 클라이언트가 없었습니다. 이제 각 요약이 **그것이 가리키는 턴 옆에** 그려집니다 — 라벨을 달고 응답 footer 아래에, 모델이 턴에 대해 쓴 글로서. 요청됐고 아직 안 온 요약은 그렇다고 말하고, 실패는 이유를 요약 자리에 보여줍니다.

그 과정에서 키를 고쳤습니다. 요약은 턴을 `turn_end` 레코드의 순번으로 불렀는데, **읽기 투영이 그 레코드를 지웁니다**(턴의 지표를 응답 행에 접은 뒤). 그래서 `AuxSummary`가 `response_seq` — 요약이 놓일 행 — 를 함께 싣습니다. 매니저가 턴을 지켜봤으니 아는 값입니다.

## 마지막 봉투를 비웠습니다

`SessionService.Library`는 열세 가지 동작을 JSON 바이트 하나에 담아 보내고 JSON 바이트 하나로 답했습니다. [#132](https://github.com/lesomnus/cxz/issues/132)가 `Project.Docker`에서 다섯 단계에 걸쳐 없앤 바로 그 모양이고, 마지막 하나였습니다.

이제 메서드 열세 개이고, **각자 의미를 가질 수 있는 인자만 받습니다.** 스토어가 첫 줄들을 "애초에 표현 가능하지 않아야 했던 조합"을 거부하는 데 쓰고 있었습니다 — 문서 쓰기는 메모리 id도 scope도 받지 않고(자기 세션의 메모리만, 휴지통은 불가), snapshot·fork·merge·rename은 scope를 받지 않고(삭제된 메모리는 복사 불가), 메모리 purge는 반대로 scope가 없습니다(이미 삭제돼 있어야 하므로).

`memorylib.Request`는 이 아래에 남습니다. 거기선 와이어 포맷이 아니라 매니저↔일회용 컨테이너 프로토콜이고, MCP 서버가 컨테이너 안에서 스토어를 직접 호출하는 경로입니다 — **에이전트는 이 API를 쓰지 않습니다.**

## 고친 것: 큰 레코드 하나가 세션을 통째로 가려던 문제

32 MiB를 넘는 커밋된 레코드 하나가 **그 앞에서 이미 읽어둔 이벤트까지** 버리게 만들었습니다. `bufio.Scanner`는 과도하게 긴 토큰 뒤로 재개할 수 없고, 호출자는 에러를 받으면 읽은 것을 버립니다. 그래서 `conversation_lookup`조차 그 세션에 대해 아무 말도 못 했습니다 — 폭주한 도구 결과 하나가 대화를 읽을 수 없게 만들었습니다.

이제 그 레코드는 **건너뛰고 이름이 붙습니다.** 응답의 `unreadable_seqs`에 순번이, `message`에 크기가 들어갑니다. `oversized_seqs`와는 다른 필드입니다 — 그쪽은 페이지 예산이라 파일·더 큰 예산·줄 범위로 받을 수 있지만, 이쪽은 어떤 요청으로도 받을 수 없습니다. 저널의 나머지는 그대로 읽히고 순번의 구멍이 응답에 보입니다.

## 재사용 가능한 UI 패키지

`@lesomnus/cxz-ui`가 공통 컨트롤과 테마 토큰을, `@lesomnus/cxz-ui/terminal`이 도킹 UI를, 선택적 `/editor`가 Monaco 계약을 갖습니다. **cxz 전송 의존성이 없습니다** — 렌더러를 주입받습니다. 애플리케이션 코드는 app·pages·features·shared·Storybook으로 분리됐습니다.
