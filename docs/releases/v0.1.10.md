# v0.1.10

프로젝트 내 에이전트 세션들이 작업을 공유하고 맡을 수 있는 Task API·내장 MCP·웹 보드를 추가했습니다. Codex 응답 대기와 세션 상태 표시, 웹 대화·입력 동작도 개선했습니다.

## 업그레이드

```sh
cxz use v0.1.10      # 또는 cxz use @stable
```

Manager와 프로젝트 runtime을 함께 업데이트하세요. Task MCP 도구는 새로 시작하거나 명시적으로 Restart한 에이전트에 적용됩니다. 기존 실행의 도구 목록은 자동 교체되지 않습니다. 프로젝트 상태 볼륨은 유지하며, Task 추가를 위해 프로젝트를 삭제하거나 재생성할 필요는 없습니다.

이번 버전은 AuthBinding의 `binding_id` protobuf 필드 번호를 변경합니다. 저장된 데이터베이스 열과 값은 유지되지만 Manager·프로젝트 runtime·직접 API 클라이언트는 같은 wire contract를 사용해야 합니다.

## 프로젝트 공유 작업

- 프로젝트별 Task를 영구 저장합니다. 세션들이 Todo, In progress, Waiting, Done, Canceled 상태와 담당 세션·run을 공유할 수 있습니다.
- Claim은 동시 요청 중 하나만 성공하며, 수정과 Release는 읽은 버전을 확인합니다. 정지·재시작·삭제된 세션의 작업은 자동 배정하지 않고 명시적으로 Release합니다.
- Task는 프로젝트 상태 볼륨에 보존됩니다. 세션을 Purge해도 작업 기록과 담당·출처 정보는 남으며, 프로젝트와 상태 볼륨을 Purge하면 삭제됩니다.
- 기본 활성화된 `cxz_tasks` MCP가 목록·상세·등록·Claim·수정·Release 도구를 제공합니다. 프로젝트·세션·run은 인증된 실행 컨텍스트에서 결정하며, 에이전트가 다른 담당자의 작업을 수정하거나 해제할 수 없습니다.
- 웹 좌측 **Tasks**에서 프로젝트별 보드를 엽니다. 작업 등록·수정, 담당/출처 세션 이동, 정지/이전 run 경고와 확인 후 Release를 지원합니다. 실시간 갱신 중에도 편집 내용을 보존하고, 충돌 시 최신 내용을 명시적으로 다시 읽습니다.
- WASM sandbox에서도 같은 Task API와 웹 보드를 사용할 수 있습니다. 별도의 CLI/TUI Task 명령은 아직 제공하지 않습니다.

자세한 계약과 사용법은 [Task 문서](../tasks.md)를 참고하세요.

## 세션과 대화

- Codex의 응답 무음 제한 시간을 기본 강제하지 않도록 변경해, 오래 걸리는 작업이 고정 대기 시간으로 중단되는 문제를 줄였습니다.
- 대화 기록의 승인 상태를 정리한 뒤 미응답 요청을 표시해, 세션 첫 로딩에 이미 처리된 Allow/Deny가 다시 나타나는 문제를 수정했습니다.
- 세션의 정지·비활성 표시를 재개 제어와 일치시키고, 불투명한 생성 키를 가진 세션의 Purge 오류를 수정했습니다.
- 응답의 `/`로 시작하는 Markdown 파일 링크를 우측 워크스페이스 파일 뷰어에서 엽니다.
- 사용자 입력 카드도 Markdown으로 표시합니다. 연속 스크롤 중 핸들 추적, 입력창 높이 변경 중 대화 하단 추적과 duration 메트릭 잘림을 개선했습니다.

## 웹 UI와 개발

- 세션 생성 메뉴·다이얼로그와 메뉴 표시 애니메이션, 간격 및 열린 메뉴의 트리거 표시를 정리했습니다.
- 패널에서 스크롤 밖의 확인하지 않은 세션 방향을 그림자 색으로 표시합니다.
- 업로드 chip의 밝기와 진행 shimmer, 전송 애니메이션 중 원래 chip이 겹치는 문제를 개선했습니다.
- Question의 취소 재확인 버튼이 hover 중에도 경고 색을 유지하도록 공용 버튼 스타일을 수정했습니다.
- Storybook에 Task 보드, 원격 수정 충돌, 업로드 및 대화 하단 추적 예제를 추가했습니다.
