# v0.1.4

브라우저에서 대화를 하는 웹 UI가 처음 정식 버전으로 공개됩니다. 대화 전체를 검색할 수 있고, 트랜스크립트는 다시 읽는 로그가 아니라 색인이 되었고, 매니저에 mTLS로 직접 붙을 수 있고, 보조 AI는 자기 API를 갖게 되었습니다.

## 업그레이드: v0.1.3에서는 자동으로 올라옵니다

상태 스키마가 v0.1.3과 같은 2입니다. v0.1.2 이하(스키마 1)에서 올라오는 경우에만 [v0.1.3의 안내](v0.1.3.md#업그레이드-v012에서는-자동으로-올라오지-않습니다)가 필요합니다.

```sh
cxz use v0.1.4      # 또는 cxz use @stable
```

`cxz use`는 idle을 기다리지 않고 강제로 재시작하므로 진행 중인 작업은 중단됩니다. 대화·계정·모델은 유지되고 마지막 입력을 다시 보내지 않습니다. 프로젝트 컨테이너와 데이터 볼륨은 유지됩니다.

## 이 릴리즈를 고정 지점으로 쓰는 경우

이 릴리즈는 `Project.Docker` 봉투를 비우는 API 재설계([#132](https://github.com/lesomnus/cxz/issues/132)) **직전**의 빌드입니다. `@edge`로 그 이후를 쓰다가 문제가 생기면 여기로 돌아옵니다.

```sh
cxz use v0.1.4      # 되돌아오기
cxz use @edge       # 다시 최신으로
```

자동 업데이트는 되돌리지 않습니다. 설치된 리비전이 새 릴리즈의 조상일 때만 적용하므로, `@edge`에서 이 릴리즈보다 앞선 빌드를 쓰고 있으면 v0.1.4는 다운그레이드로 판단되어 거부됩니다. 돌아오려면 위의 `cxz use v0.1.4`를 직접 실행해야 합니다.

## 웹 UI

브라우저에서 대화를 하고, 프로젝트를 만들고, 설정을 고칩니다. 설치의 게이트웨이를 한 번 띄우면 됩니다.

```sh
cxz web up                # 백그라운드 게이트웨이 컨테이너를 만듭니다
cxz web status            # 무엇이 돌고 있고 최신인지 보고합니다
cxz web down              # 컨테이너만 지웁니다; 설정과 토큰은 유지됩니다
```

기본값은 루프백 평문입니다. 브라우저가 `127.0.0.1`을 보안 출처로 취급하므로 인증서·호스트명·신뢰 저장소를 **페이지를 열기 전에 준비해야 하는 것이 하나도 없습니다**. 게이트웨이는 접근 토큰으로 인증하고, RPC 응답에서 편집기의 비공개 토큰을 제거하고, workbench 쿠키를 프록시 범위로 한정합니다.

- **대화**: 가상화된 스크롤, 방향성 페이드, 바로 앞 입력 고정, 떠 있는 카드로 표시되는 질문과 상세, 응답 호버 강조, 최종 응답의 모델·effort·지표.
- **입력창**: Monaco를 설정 화면과 공유하고, 줄 번호·인라인 코드·코드 펜스·들여쓰기·붙여넣기 칩을 지원하며, 질문 답변에도 같은 편집기를 씁니다.
- **작업 공간**: 미리보기, devcontainer 편집기, 컨테이너 터미널, 프로젝트 탐색.
- **설정**: 주제 탐색과 JSON 창, 공유 컨트롤, 모양 설정, 상속되는 브라우저 편집기 설정.
- **언어**: 기본 영어이고 언어 팩은 필요할 때 내려받습니다.

웹 자산은 이제 매니저 이미지 안의 파일에서 서빙합니다. 설치가 자기 이미지에서 자산을 꺼내므로 호스트에 Node가 필요 없습니다.

개발용으로는 로컬 Vite 프록시와 자동 게이트웨이 로그인, [Storybook](https://github.com/lesomnus/cxz/blob/v0.1.4/docs/storybook.md) 컴포넌트 미리보기, payday WASM 샌드박스가 있습니다. 샌드박스는 Docker·자격 증명·유료 에이전트 없이 실제 UI를 띄웁니다.

## 대화 검색

설치가 가진 모든 프로젝트의 모든 대화를, 한 번에 한 시간 창씩 최신부터 찾습니다.

```sh
cxz conversation search TEXT                 # 모든 프로젝트, 최근 30일
cxz conversation search --match regex|fuzzy --ignore-case TEXT
cxz conversation search --project NAME --exclude NAME TEXT
cxz conversation search --since 2026-08-01 --until 2026-09-01 TEXT
cxz conversation search --window 7d --limit 50 --snippet 300 TEXT
cxz conversation search --continue CURSOR
cxz conversation search --tools --progress TEXT
```

창은 반열린 구간이라 연속한 창이 겹치지도 빠뜨리지도 않습니다. 답은 이벤트가 기록될 때 함께 갱신되는 색인에서 나오고, **색인이 아직 따라가지 못한 대화는 조용히 빠지는 대신 그렇다고 보고합니다**. TUI에서도 찾고 트랜스크립트에서 일치 부분을 칠합니다. 공유 메모리 MCP에도 프로젝트 범위 검색과 스냅샷 내보내기가 추가되어, 에이전트가 자기 프로젝트의 과거 대화를 읽을 수 있습니다.

## 트랜스크립트는 색인입니다

대화를 다시 읽는 로그가 아니라 색인으로 다룹니다. 트랜스크립트 페이지는 프로토콜 레코드가 아니라 **읽을 수 있는 행**을 셉니다.

- 네이티브 이벤트 상세는 볼 때만 가져옵니다.
- 요약은 더 큰 창으로 읽습니다.
- 도구 생애주기는 한 줄 상태 행으로 묶습니다.
- 끝난 턴의 알림은 최종 응답의 꼬리말로 접습니다.
- 내부 프로토콜과 텔레메트리 이벤트는 트랜스크립트에 넣지 않습니다.
- 저널의 꼬리를 한 번에 읽고, 그 과정에서 세션을 잃지 않습니다.

모델 카탈로그도 탐색하는 대신 서빙합니다.

## mTLS 연결과 터널

SSH를 거치지 않고 매니저에 직접 붙습니다. 설치 루트의 비공개 키는 매니저의 상태 볼륨에 남고, 증명서와 CSR만 오갑니다.

```sh
cxz connection ls
cxz connection enroll NAME                  # SSH로 이 클라이언트의 증명서를 받습니다
cxz connection enroll --csr NAME            # ...또는 직접 서명할 요청을 출력합니다
cxz connection check NAME                   # 지금 relay에 붙어서 무엇이 답하는지 보고합니다
cxz connection forget NAME
cxz connection tunnel [--local-port 7350] [--remote-port 7350] NAME
cxz --endpoint mtls://host:7349
```

터널은 저장된 SSH 연결을 쓰고 클라이언트 IPv4 루프백에만 바인드합니다. Ctrl+C로 닫아도 서버 작업은 멈추지 않습니다.

## 보조 AI

보조 AI가 자기 API를 갖게 되었습니다([설계 노트](https://github.com/lesomnus/cxz/blob/v0.1.4/docs/plans/aux-api.md)). Aux는 세션에 딸려 한 번 수행되고 끝나는 모델 작업이고, 문맥은 cxz가 구성해서 넘기며 대화로 쌓이지 않습니다. 요약·추천·제목은 Aux의 kind입니다.

작업이 한 번만 수행되고 여러 클라이언트가 같은 결과를 봅니다. 결과는 매니저가 들고 있다가 스트림으로 밀어주므로, TUI와 웹 UI가 같은 요약을 같은 시점에 봅니다. 세션 제목도 보조 AI가 짓고, 사이드바는 두 줄 항목으로 보여줍니다. 다른 작업의 프로필을 그대로 쓰겠다고 할 수 있습니다.

```sh
cxz ai list
cxz ai models ACCOUNT
cxz ai login ACCOUNT
cxz ai set summary    --account ACCOUNT --model MODEL [--effort EFFORT]
cxz ai set suggestion --account ACCOUNT --model MODEL [--effort EFFORT]
cxz ai disable summary|suggestion
cxz ai status SESSION
cxz ai cancel SESSION
```

## 벤더 스트림을 대화와 따로 둡니다

저널에는 프로바이더가 보낸 바이트가 그대로 남습니다. 그 기록은 가치가 있지만 **바이트의 대부분이기도 합니다**. 측정한 설치 하나에서 저널 275 MiB 중 verbatim 스트림이 194 MiB였고, 실제로 *말한* 것은 0.35 MiB — 약 800분의 1이었습니다.

예산이 하나였을 때 한도에 닿는 것은 그 194 MiB이고, 뒤따르는 트림은 턴을 지웁니다. 텔레메트리가 함께 도착한 대화를 밀어내는 것입니다. 그래서 스트림에 자기 예산이 생겼습니다.

| | 위치 | 기본값 |
|---|---|---|
| 서버 보존 | Manager | 세션당 100 MiB |
| **벤더 스트림** | Manager | **세션당 20 MiB** |
| 클라이언트 윈도 | TUI | 10 MiB 또는 200턴 |

한도를 넘으면 안전한 idle 시점에 **가장 오래된 payload를 예산의 80% 수준까지 비우고** `history_shed` 레코드를 남깁니다. 이벤트는 남습니다 — 내용이 빈 raw 이벤트도 "이 턴이 스트림을 만들었다"는 말은 하지만, 지워버린 이벤트는 스트림이 애초에 없던 턴과 구별되지 않습니다. 가장 최근 턴은 절대 비우지 않습니다. `Ctrl+.`에서 세 예산을 모두 조정합니다. 벤더 스트림에는 "끔"이 없습니다 — 보존을 끄는 것은 스위치 하나이고, 충분히 큰 예산이 전부를 남기는 방법입니다.

## 입력창

bed 편집기를 TUI 입력창에 통합했습니다. 다중 커서, 줄 편집, 공백 표시 토글, 줄바꿈된 행 구분, 독립 스크롤, 단어 단위 트랜스크립트 선택을 지원합니다. 멈춘 Codex 응답을 복구하고, 세션 멘션은 프로젝트 범위의 별칭 격자에서 완성합니다.

## 그 외

- `cxz project recreate --yes @all`로 실행 중인 소유 프로젝트 전부를 한 대상으로 다시 만듭니다.
- 하루 단위 대화 통계를 범위를 지정해 읽습니다([conversation-stats.md](https://github.com/lesomnus/cxz/blob/v0.1.4/docs/conversation-stats.md)).
- `F2`로 프로젝트 제목을 바꾸고, 승인용 기능 키는 없앴습니다.
- CLI 명령을 목적별로 묶어 도움말에 보여줍니다.
- 조용한 초록 위에 백그라운드 전용 세션을 띄웁니다.
