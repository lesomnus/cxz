# v0.1.1

긴 대화에서 TUI를 다시 그릴 때 과거 실행의 출력 조각을 불필요하게 합치던 비용을 줄였습니다. 현재 실행이 작업 중일 때만 실시간 출력을 합칩니다. 과거 대화와 저장된 출력은 그대로 보존됩니다.

- 과거 실행의 출력과 idle 세션의 출력이 실시간 출력으로 표시되지 않는 회귀 테스트를 추가했습니다.
- 출력 조각 2,000개·8,000개가 누적된 대화를 측정하는 렌더 벤치마크를 추가했습니다.

로컬 Linux/amd64 벤치마크(동일 환경, 3회 측정 중앙값)에서 과거 출력 8,000개를 포함한 렌더 시간은 약 4.0ms → 0.65ms, 렌더당 메모리 할당은 약 6.5MB → 1.1KB로 줄었습니다. 실제 개선 폭은 대화 내용과 실행 환경에 따라 달라집니다.

설치 및 버전 고정:

```sh
cxz use v0.1.1
```

진행 중인 작업을 중단하고 로컬 관리 구성 요소를 강제로 재시작합니다. 필요하면 `cxz use v0.1.0`으로 복귀할 수 있습니다. 기존 v0.1.0 릴리즈는 유지됩니다.
