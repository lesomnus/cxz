# v0.1.0

자동 업데이트 시험 중 돌아올 수 있는 안정된 기준 릴리즈입니다.

- `cxz use v0.1.0`: 검증된 릴리즈 실행 파일과 Manager 이미지를 설치하고 버전을 고정합니다.
- 로컬 Manager, 실행 중인 프로젝트 Runtime, Supervisor와 Agent를 강제로 재시작합니다. 진행 중인 작업은 중단되며, 대화·계정·모델은 유지하고 입력을 중복 실행하지 않습니다.
- `cxz use`: 고정 상태를 확인합니다. `cxz use --unpin`: 재시작 없이 고정을 해제합니다.
- 버전 교체 도중 실패하면 같은 명령으로 재개할 수 있습니다. 프로젝트 컨테이너·볼륨은 유지됩니다.
- Windows와 원격 클라이언트는 클라이언트만 교체합니다. 연결된 호스트에는 별도로 명령을 실행합니다.

자동 업데이트 기능은 별도 PR이며 이 릴리즈에 포함되지 않습니다.

자세한 범위와 복구 절차: [버전 고정 문서](https://github.com/lesomnus/cxz/blob/v0.1.0/docs/version-pinning.md)
