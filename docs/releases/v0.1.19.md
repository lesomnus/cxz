# v0.1.19

Task·Memory 상세 화면과 클라이언트 오류 진단을 보완하고, 대화 옆 파일 뷰어와 공통 UI를 정리했습니다.

## Task와 Memory

- Task 전용 상세 페이지에서 인접 작업을 미리 보고 이동할 수 있습니다. 제목·설명·기본 정보·작업 버튼의 배치를 정리하고, 완료된 작업은 읽기 전용으로 표시합니다.
- 작업 배정·해제·검토 요청·취소 동작을 보완하고, 변경 이력을 상세 화면과 API·내장 MCP에서 제공합니다. 페이지 전환 중에도 이력을 유지합니다.
- Memory 문서 본문을 Payday Queries로 캐시하고, 상세 화면을 다시 열 때 이미 읽은 내용을 유지합니다.
- 프로젝트·계정·Task·Memory 화면에 공통 레이아웃, 탐색 버튼과 페이지 전환을 적용했습니다.

## 파일 뷰어와 대화 입력

- 파일 탭 관리, 경로 복사, Markdown 미리보기와 구문강조 자동 탐지·수동 선택을 제공합니다.
- 대화 입력 메뉴와 파일 메뉴가 편집 옵션 UI를 공유합니다. 파일 메뉴에서 탭·공백 입력, 제어 문자 표시, 자동 줄바꿈을 설정하고 저장할 수 있습니다.
- 좁은 대화 화면의 파일 뷰어는 위에서 내려오는 오버레이로 열립니다. 하단 경계를 끌어 높이를 바꾸고, 우측 하단 바깥의 버튼으로 닫을 수 있습니다. 다시 열 때 높이와 열린 파일을 유지합니다.
- 붙여넣기 chip의 커서 이동, 자동 줄바꿈과 한글 조합 중 표시를 보완했습니다.
- 프로젝트 컨테이너가 없는 상태에서도 백그라운드 작업 상태를 확인할 수 있도록 조회 경로를 수정했습니다.

## 오류 진단과 공통 UI

- Errors 페이지에서 오류 종류·원인·대상·진단 정보를 같은 테이블 구조로 확인하고, 행을 눌러 상세 다이얼로그를 열 수 있습니다.
- 진행 중인 오류와 복구·지난 이력을 구분하고, 개별·일괄 해제 동작을 제공합니다. RPC와 터미널 오류에 구조화된 진단 정보를 보존합니다.
- 메뉴·팝오버·카드·숫자·날짜·사용량 그래프 등 공통 요소를 Nox로 통합하고, 선택 상태와 키보드 동작·등장 효과·간격을 정리했습니다.

Task 변경 이력 API를 사용하려면 Manager와 프로젝트 runtime도 업데이트해야 합니다.

```sh
cxz use v0.1.19
```
