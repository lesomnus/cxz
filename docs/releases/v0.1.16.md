# v0.1.16

대화 입력창의 첨부·붙여넣기·Secret 처리를 개선하고, 공통 Nox 컴포넌트로 폼과 메뉴의 배치·동작을 정리했습니다.

## 대화 입력

- 붙여넣기 칩에서 텍스트와 파일 전송 방식을 직접 선택할 수 있습니다. 짧은 내용은 바로 입력하고, 내용 길이에 따라 기본 전송 방식을 선택합니다.
- 파일 칩의 크기와 네이티브 커서 위치를 맞추고, 한글 조합·브라우저 배율·고정폭 폰트에서의 배치 회귀를 보완했습니다.
- 붙여넣기 칩을 누르면 입력창 위 카드에 원문을 표시합니다. 파일 메타데이터나 중첩 상자 없이 전문을 보여주며, 확장과 닫기 동작은 하단에 배치했습니다.
- 업로드 완료 응답을 기다리는 동안에는 진행률을 99% 이하로 유지하고, 실제 사용 가능해지면 파일 크기로 전환합니다.
- 파일을 화면 안으로 끌어오면 대화 입력 위치를 표시합니다. Alt+Z로 입력창 줄바꿈을 전환할 수 있습니다.

## Secret과 공통 UI

- 인식 가능한 토큰 전체를 붙여넣으면 Web과 TUI의 공통 규칙으로 Secret 저장소에 전달합니다. Secret 미리보기는 값을 가리고, 전문 확장은 확인을 거칩니다.
- Task 편집의 Priority와 Status를 첫 행에 배치하고, 공통 Form과 선택 메뉴를 사용합니다.
- 선택된 값과 겹쳐 열리는 메뉴의 깜빡임·정렬과 비활성 항목의 표시를 개선했습니다.
- 페이지를 이동할 때 현재 프로젝트 선택을 유지합니다.
