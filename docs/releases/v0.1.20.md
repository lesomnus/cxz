# v0.1.20

세션 목록과 대화 탐색, Memory 버전 비교, 보조 AI 설정과 백그라운드 작업 메뉴를 개선했습니다.

## 세션과 대화

- 세션 목록을 공통 테이블로 정리하고 최근 대화 순 정렬, 미확인 완료 표시와 비활성 세션 스타일을 적용했습니다. 컨테이너가 없는 프로젝트의 세션은 목록에서 제외합니다.
- 세션 목록과 대화 사이 이동에 전환 효과를 적용하고, 돌아왔을 때 목록의 선택과 스크롤 위치를 유지합니다.
- 대화의 작업 요약에서 생성된 Task와 Memory를 메뉴로 확인하고 상세 화면을 열 수 있습니다. Memory 변경 내역에는 리비전과 바이트 증감도 표시합니다.
- 백그라운드 작업 메뉴는 진행 중인 항목을 먼저, 최근 종료 항목을 제한해서 표시합니다. 명령어 구문강조와 경과 시간을 제공하고, 캐시를 사용해 다시 열 때 목록 높이가 바뀌는 현상을 줄였습니다.
- 백그라운드 명령어와 설명을 분리했습니다. Claude의 설명은 일반 텍스트로, 설명이 없는 Codex 작업은 명령어로 표시합니다. 기존 Codex 기록은 원본 이벤트를 확인할 수 있는 경우 자동으로 보정합니다.
- 큰 붙여넣기 chip의 삭제·실행 취소·다시 실행과 `Ctrl+Shift+V` 확장 붙여넣기를 보완했습니다. 작성 중인 질문 답변도 새로고침과 화면 이동 후 유지합니다.

## Memory와 보조 AI

- Memory를 문서 카드 목록과 별도 상세 화면으로 정리하고, 프로젝트·세션 필터와 목록 캐시를 적용했습니다.
- 상세 화면에서 리비전 선택과 이전 버전 비교, 단어 단위 강조, 추가·삭제된 UTF-8 바이트 수를 제공합니다.
- 보조 AI의 Summary·Suggestion·Title은 하나의 계정을 공유합니다. 계정·모델·effort·로그인·저장·되돌리기와 기능별 토글을 한 화면에서 설정할 수 있습니다.
- 이전 보조 AI 설정은 Manager 시작 시 공유 계정으로 이관합니다. 계정이 바뀌면 해당 계정에 속하지 않는 설정을 비활성화하고 모델·effort를 초기화합니다.

## 설정과 진단

- 설정 화면의 배치와 스크롤 탐색을 정리하고 클라이언트 로그를 별도 페이지로 분리했습니다.
- 사용자가 보고 있는 대화의 일시적 조회 오류와 선택적 조회 실패는 불필요한 경고를 만들지 않도록 조정했습니다.
- fork한 세션의 과거 대화가 새 완료 알림으로 처리되지 않도록 저장된 경계 정보를 사용합니다.
- 공통 Nox 메뉴·드롭다운·날짜 필터·스위치·페이지 전환 스타일을 갱신했습니다.

공유 계정 설정, Memory 버전 통계와 백그라운드 명령어 변경을 사용하려면 Manager와 프로젝트 runtime·Supervisor도 업데이트해야 합니다. 기존 DB를 삭제할 필요는 없습니다.

```sh
cxz use v0.1.20
```
