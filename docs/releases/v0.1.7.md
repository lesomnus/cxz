# v0.1.7

웹의 음성 입력, 컨테이너 경로 완성, 질문 응답 기록을 개선한 릴리즈입니다.

## 업그레이드

```sh
cxz use v0.1.7      # 또는 cxz use @stable
```

## 음성 입력

Composer toolbar의 마이크 버튼으로 브라우저 음성 인식을 시작하고, 다시 누르거나 Escape로 종료합니다. 인식된 문장은 초안에 삽입되며 자동으로 전송하지 않습니다. 녹음 표시와 입력창의 파형으로 활성 상태를 확인할 수 있습니다. 지원되지 않는 브라우저에서는 버튼이 비활성화됩니다.

기본 인식 언어는 브라우저의 선호 언어를 따릅니다. **Settings → General → Voice input**에서 언어를 선택하거나 브라우저 기본값으로 돌아갈 수 있습니다. 기존 언어 선택은 유지됩니다. 같은 설정에서 로컬 인식을 강제할 수 있지만, 실제 지원 여부와 온라인 인식 서비스는 브라우저에 따라 다릅니다.

## 명령어와 컨테이너 경로 완성

- 첫 `/` 명령어 힌트를 Tab으로 완성할 수 있습니다.
- 단일 백틱 안에서 `/` 또는 `~`로 시작하는 경로를 입력하면 컨테이너의 파일·디렉터리 후보가 표시됩니다. 입력 중인 줄을 가리지 않으며, 유사도가 높은 후보부터 커서 가까이에 배치합니다.
- 네 방향키로 격자를 탐색하고 Tab·Enter·클릭으로 선택합니다. Escape는 힌트를 닫습니다. 디렉터리를 선택하면 하위 경로를 이어서 완성합니다.
- 디렉터리, 실행 파일, 심볼릭 링크, 파이프, 소켓, 장치 파일을 색으로 구분하고 hover로 종류를 확인합니다. 구형 runtime은 기존 디렉터리·링크·실행 가능 정보로 표시합니다.
- `/download <경로>`는 에이전트에게 메시지를 보내지 않고 기존 프로젝트 다운로드 API로 파일을 저장합니다. 같은 경로 완성을 사용할 수 있습니다.

Vite의 UI 갱신만으로 실행 중인 서버가 바뀌지는 않습니다. 구형 웹 서버가 `path outside project workspace`를 반환하면 웹 서버도 업데이트해야 합니다. 자세한 절차는 [웹 개발 안내](../web.md#developing-the-ui-against-the-installed-manager)를 참고하세요.

## 질문 응답 기록

질문의 선택 항목과 직접 입력한 답변을 기록하고, 대화에서 완료·취소 상태와 함께 확인할 수 있습니다. 여러 단계 질문은 초안과 선택을 유지하며 이동합니다. 기존 기록에 답변 내용이 저장되지 않은 경우에는 기록이 없다고 표시합니다. 신규 답변 저장에는 업데이트된 supervisor가 필요합니다.
