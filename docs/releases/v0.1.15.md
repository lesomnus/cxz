# v0.1.15

세션 대화, 파일 미리보기와 리소스 화면을 개선하고 공유 Nox UI 구성요소를 통합했습니다.

## 웹 UI

- 대화 사이의 작업 요약에 전체 작업 수와 공유 메모리·Task 호출 수, 경과 시간을 구분해 표시합니다. Codex의 MCP 실행 시작·완료 기록을 하나의 작업으로 묶고, 확인된 내장 MCP 호출도 작업 상세에 포함합니다.
- 컨테이너 파일 링크를 파일 아이콘과 메타데이터가 있는 칩으로 표시합니다. 누르면 세션의 읽기 전용 파일 뷰어에서 열리며, 좁은 화면에서는 위쪽에서 내려오는 뷰어를 사용합니다.
- 입력창 메뉴에 에디터 옵션을 모으고, 전송 대기 중인 입력과 실패 후 초안 복원 동작을 개선했습니다. 과거 대화를 읽는 동안 Latest 버튼이 유지됩니다.
- 프로젝트 Actions를 섹션 전체가 클릭되는 형태로 바꾸고, 계정 화면과 리소스 정보에 공통 섹션·필드·Popover 스타일을 적용했습니다.
- Question 본문에 Markdown과 단계별 페이지 전환을 적용했습니다. Task 화면과 작업 수 표시의 배치도 정리했습니다.
- 메뉴 스크롤바를 메뉴 바깥에 배치하고, 레일을 눌러 이동하거나 이어서 드래그할 수 있게 했습니다. 공유 선택 메뉴에는 선택 항목을 기준으로 위아래로 펼쳐지는 옵션을 추가했습니다.

## 업데이트

```sh
cxz use v0.1.15
```

새로운 Codex MCP 호출 정보를 기록하려면 Manager와 프로젝트 runtime을 함께 업데이트하세요. 이전에 기록되지 않은 호출은 과거 대화에 소급해서 추가되지 않습니다.
