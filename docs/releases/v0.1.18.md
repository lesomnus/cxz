# v0.1.18

웹의 프로젝트·세션·Task·Memory 화면을 정리하고, 목록 동기화와 캐시, 공통 선택 상태, 오류 확인 흐름을 개선했습니다.

## 프로젝트와 세션

- 프로젝트 목록에 최근 활동 세션, 상태 아이콘, 선택 및 일괄 작업을 제공합니다. 프로젝트 상세의 세션 목록도 같은 테이블 배치를 사용합니다.
- 체크박스 드래그·Shift 범위 선택과 선택 상태의 실행 취소·다시 실행을 지원합니다.
- 프로젝트 목록과 상세 사이에 페이지 전환을 적용하고, 상단 작업 버튼과 컨테이너 식별자 표시를 정리했습니다.
- 세션 패널에서 프로젝트 접기 상태를 유지하고, 대화 메뉴에 Erase를 제공합니다.

## Task와 Memory

- Task를 생성 시각 역순의 테이블로 표시하고 Done 항목은 뒤에 배치합니다. 오늘·어제 변경된 Done 항목을 우선 표시하고, 오래된 완료 항목은 50개씩 펼칠 수 있습니다.
- 초기 목록은 List로 모아서 한 번에 표시하고, 변경분 전용 Watch와 버전 기준으로 병합합니다. 로딩·재연결 중에는 기존 캐시를 유지합니다.
- Task 생성 화면에 심볼과 설명을 함께 표시하는 우선순위 선택 컨트롤을 추가했습니다.
- Memory 목록을 문서 카드로 바꾸고, 메타데이터 캐시와 세션별 필터를 적용했습니다. 변경 이력에는 인접 버전의 추가·삭제 줄 수를 제공합니다.
- Tasks와 Memory가 프로젝트·세션 선택을 공유합니다. 같은 탭의 새로고침에도 선택을 복원하며, 서버·사용자별로 분리하고 로그아웃할 때 지웁니다.
- Projects·Tasks·Memory의 상단바와 본문 정렬은 공통 레이아웃 토큰을 사용합니다.

## 검색과 계정

- Search 화면의 검색창과 날짜 필터를 정리하고 프로젝트·설치 범위 검색을 제공합니다.
- 계정 정보와 사용량 조회를 캐시하고, 새로고침 중 기존 값을 유지합니다. 사용량 숫자의 전환과 잔량 그래프 표시도 보완했습니다.
- 리소스 생성 확인 버튼을 통일하고, 세션 생성의 모델은 에이전트 기본값을 사용합니다.

## 공통 UI와 진단

- 사이드바 오류 센터에서 진행 중인 API 오류와 복구된 이력을 확인할 수 있습니다. 재시작한 요청이나 화면 이탈만으로 오류를 복구 처리하지 않습니다.
- 펼친 코드 블록의 폭과 도구 위치, 메뉴·스크롤·숫자 표시의 정렬과 전환을 개선했습니다.
- 공통 Card의 등장 효과와 배경 블러를 함께 사용할 때의 표시를 보완했습니다.

Task의 새로운 동기화 준비 신호를 사용하려면 Manager와 프로젝트 runtime도 업데이트해야 합니다.

```sh
cxz use v0.1.18
```
